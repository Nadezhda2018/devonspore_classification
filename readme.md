# Поиск похожих спор по изображениям с использованием EfficientNet-B2 и PCA

Проект реализует пайплайн извлечения визуальных признаков из изображений спор грибов (с упором на род *Agaricus* и другие роды), снижения размерности пространства признаков, кэширования индекса и косинусного поиска **Top-K** наиболее близких изображений с автоматической генерацией отчёта в формате `.docx`.

## Основные возможности

- **Извлечение признаков (`SporeFeatureExtractor`)**: использование предобученной модели `EfficientNet-B2` (`torchvision`) для получения эмбеддингов изображений с опциональной нормализацией (`StandardScaler`) и сжатием размерности (`PCA`).
- **Построение и кэширование индекса (`build_or_load_index`)**: обход каталога изображений, вычисление векторов признаков, обучение/применение `StandardScaler` и `PCA` и сохранение индекса в `.npz` для повторного быстрого запуска.
- **Косинусный поиск Top-K (`search_similar`)**: поиск наиболее похожих изображений спор по косинусному сходству векторов признаков.
- **Пакетная обработка по родам (`process_genus_batch`)**: формирование выборок запросов, поиск похожих экземпляров и сбор результатов для дальнейшего анализа.
- **Визуализация и отчётность**: построение коллажей/сравнений и графиков метрик (`matplotlib`, `PIL`), а также формирование итогового отчёта в `.docx` (`python-docx`).

## Структура проекта

- `*.ipynb` — основной Jupyter Notebook с реализацией пайплайна (предобработка, извлечение признаков, построение индекса, поиск, визуализация и экспорт в `.docx`).
- `spores_index_final.npz` / `spores_index_all.npz` — кэш вычисленных эмбеддингов, параметров `StandardScaler` и `PCA` и метаданных изображений (создаётся автоматически при запуске).
- `README.md` — документация проекта.

Для работы ноутбука требуются библиотеки:

- `numpy`
- `torch`, `torchvision`
- `scikit-learn`
- `pillow` (`PIL`)
- `matplotlib`
- `python-docx`

Установка основных зависимостей:

```bash
pip install numpy torch torchvision scikit-learn pillow matplotlib python-docx
```

## Использование

1. Откройте ноутбук (`.ipynb`) в Jupyter Notebook, JupyterLab или VS Code.
2. Укажите пути к директории с изображениями спор и путь к файлу кэша индекса (например, `spores_index_final.npz`).
3. Запустите ячейки последовательно:
   - инициализация модели `EfficientNet-B2` и `SporeFeatureExtractor`;
   - построение или загрузка индекса признаков через `build_or_load_index`;
   - выполнение поиска похожих спор (`search_similar` / `process_genus_batch`);
   - генерация графиков и сохранение итогового отчёта в `.docx`.

## Примечания

- При наличии GPU (`CUDA`) вычисления на `EfficientNet-B2` автоматически ускоряются; при отсутствии GPU код выполняется на CPU.
- При изменении параметров модели или размерности `PCA` рекомендуется пересобрать кэш-файл `.npz`, чтобы избежать несоответствия размерностей векторов.
